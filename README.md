# E-Commerce Console System (C++17)

A command-line e-commerce application developed as a graduation project milestone, focusing on modern C++ principles, file persistence, and automated testing.

## Table of Contents
- [Features](#features)
- [Project Structure](#project-structure)
- [Getting Started](#getting-started)
- [Running Tests](#running-tests)

## Features
- **Role-Based Access:** Customer and Administrator menus.
- **Catalog Management:** Add, update, and browse products.
- **Cart & Checkout System:** Manage quantities, calculate totals, and process secure orders with stock verification.
- **Persistence:** Local file storage for products and orders.

## Project Structure
- `src/` - Source code implementation files.
- `include/` - Header files containing class definitions.
- `tests/` - Unit tests verifying application logic.
- `docs/` - Project documentation and final reports.
